# Tunisia Digital Health

Initial React application for the Tunisia Digital Health project. Website content and features are still being planned.

## Stack

- React and TypeScript
- Vite for development and production builds
- Oxlint for linting

## Getting started

Use Node.js 24 LTS and npm.

```sh
npm ci
npm run dev
```

Open the local URL printed by Vite.

## Commands

```sh
npm run lint     # Check source code
npm run build    # Type-check and build into dist/
npm run preview  # Preview the production build locally
```

The placeholder page is in `src/App.tsx`. Global styles are in `src/index.css`, and page styles are in `src/App.css`.
